# ⏱ Cool Timer App

ダーク系グラデーションUIのタイマー・ストップウォッチアプリです。

## 機能

### タイマー
- プリセットボタン（1分 / 3分 / 5分 / 10分 / 25分）
- 分・秒の手動入力
- SVGリングアニメーションで残り時間を可視化
- 終了時にベルアラート（Web Audio API）＋オーバーレイ通知

### ストップウォッチ
- ミリ秒（0.03秒精度）の計測
- ラップタイム記録（スプリット＋累計）
- SVGリングが60秒サイクルで回転

## 使い方

`index.html` をブラウザで直接開くだけで動作します。サーバー不要。

## 技術スタック

- HTML5 / CSS3 / Vanilla JavaScript
- SVG アニメーション
- Web Audio API（アラーム音）
